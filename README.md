# Музыкальный бот для Discord

Бот поддерживает команды `/play запрос:<название или ссылка>`, `/skip` и `/stop`. Он ищет музыку на YouTube, принимает ссылки на ролики и плейлисты YouTube, а также ссылки SoundCloud. Для Spotify и Яндекс Музыки бот берёт название трека из ссылки и ищет доступную версию на YouTube: эти ссылки не дают боту прямой аудиопоток. Перед отправкой в Discord звук проходит нормализацию громкости. Когда очередь опустеет, бот отключится от голосового канала через минуту.

## Запуск

1. Создай приложение и бота на [Discord Developer Portal](https://discord.com/developers/applications), скопируй токен бота и ID приложения.
2. Включи для приглашения бота scopes `bot` и `applications.commands`, а из разрешений добавь `Connect`, `Speak` и `Send Messages`.
3. Установи Node.js 26 или новее. Проект использует актуальный потоковый модуль YouTube, которому нужна Node.js 26+.
4. В папке проекта выполни:

   ```powershell
   npm install
   Copy-Item .env.example .env
   ```

5. Заполни `DISCORD_TOKEN` и `CLIENT_ID` в `.env`. Чтобы команды появились сразу на одном сервере, укажи там `GUILD_ID`.
6. Зарегистрируй команды и запусти бота одним из способов.

   Двойной щелчок по `start.bat` автоматически установит зависимости, зарегистрирует команды и запустит бота. При первом запуске скрипт создаст `.env` и откроет его для заполнения.

   Или выполни команды вручную:

   ```powershell
   npm run commands:register
   npm start
   ```

Оставь процесс `npm start` запущенным. Для работы бота ему нужны доступ к Discord и источникам аудио, а пользователю, который вызывает `/play`, нужно находиться в голосовом канале.

Если YouTube ограничивает воспроизведение, попробуй обновить `play-dl` (`npm update play-dl`). Поведение внешних музыкальных сервисов может меняться; для Spotify и Яндекс Музыки поиск идёт по названию, а звук проигрывается с YouTube.
